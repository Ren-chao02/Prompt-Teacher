# 角色扮演提示词

通过设定特定角色，让AI从专业角度回答问题，提升输出的专业性和针对性。

## 为什么有效？

- **专业知识**：激活特定领域的知识
- **语言风格**：匹配目标受众
- **思维模式**：采用特定视角思考

## 常用角色类型

1. **专家角色** - 技术专家、领域专家
2. **用户角色** - 初学者、高级用户
3. **创意角色** - 作家、设计师、艺术家
4. **分析角色** - 分析师、顾问

## 实战技巧

::: tip 关键点
角色描述越具体，效果越好。
:::
