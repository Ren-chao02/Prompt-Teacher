# 常用提示词技巧

本章将介绍一些经过验证的提示词技巧，帮助你快速提升提示词的效果。

## 技巧清单

### 1. 少样本学习 (Few-Shot Learning)
提供几个示例让AI理解你的期望。

### 2. 链式思维 (Chain-of-Thought)
引导AI逐步推理复杂问题。

### 3. 角色扮演 (Role Playing)
设定特定角色来获得专业视角的回答。

### 4. 分解任务 (Task Decomposition)
将大任务拆分成小步骤。

### 5. 迭代优化 (Iterative Refinement)
通过多轮对话逐步完善结果。

## 实践建议

::: warning 重要提醒
技巧不是一成不变的，需要根据具体场景灵活运用。
:::
