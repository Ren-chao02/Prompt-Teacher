# 提示词的基本结构

## 概述

掌握提示词的基本结构是写出高质量提示词的基础。本章将详细介绍提示词的各个组成部分以及如何有效地组织它们。

## 核心要素

### 1. 角色设定 (Role)

角色设定决定了AI回答问题的视角和风格。

**示例：**
```
你是一位资深的数据科学家，拥有10年的机器学习经验...
```

### 2. 任务描述 (Task)

清晰的任务描述是提示词的核心。

**示例：**
```
请解释什么是过拟合（overfitting），并说明如何防止它...
```

### 3. 上下文信息 (Context)

提供足够的背景信息帮助AI理解你的需求。

**示例：**
```
我正在做一个房价预测项目，使用的是线性回归模型...
```

### 4. 输出格式 (Format)

指定你期望的输出形式。

**示例：**
```
请用以下格式回答：
- 定义
- 原因分析
- 解决方案
- 代码示例
```

### 5. 约束条件 (Constraints)

添加限制条件来控制输出的质量和长度。

::: tip 最佳实践
好的约束条件应该具体、可衡量、可实现。
:::

## 结构模板

以下是一个通用的提示词结构模板：

```markdown
[角色设定]

[任务描述]

背景信息：
[上下文]

要求：
1. [约束1]
2. [约束2]
3. [约束3]

输出格式：
[格式说明]
```

## 实战案例

让我们通过一个完整的例子来理解这些要素的协同作用。

### 案例：编写技术文档

**❌ 简单版本：**
```
写一份API文档
```

**✅ 完整版本：**
```
角色：你是一位专业的技术文档工程师，擅长编写清晰易懂的API文档。

任务：为以下Python函数编写API文档

函数代码：
def calculate_bmi(weight, height):
    """
    计算身体质量指数 (BMI)
    
    Args:
        weight: 体重（公斤）
        height: 身高（米）
    
    Returns:
        BMI值
    """
    return weight / (height ** 2)

背景：
这是一个健康管理应用的核心函数，目标用户是初级开发者

要求：
1. 包含函数说明、参数说明、返回值说明
2. 提供至少2个使用示例
3. 说明可能的异常情况
4. 使用中文，语言简洁明了
5. 总字数控制在500字以内

输出格式：
## 函数名称
### 说明
### 参数
### 返回值
### 示例
### 注意事项
```
