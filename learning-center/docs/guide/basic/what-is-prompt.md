# 什么是提示词

## 概述

提示词（Prompt）是与AI模型交互的核心方式，它是你向AI发出的**指令、问题或请求**。好的提示词能够引导AI生成更准确、更有用的回答。

::: tip 核心概念
提示词工程（Prompt Engineering）是一门关于如何设计和优化提示词的艺术和科学，旨在最大化AI模型的性能和输出质量。
:::

## 为什么提示词重要？

在人工智能时代，**会写提示词**就像在互联网时代**会使用搜索引擎**一样重要。掌握提示词技能，你可以：

- ✅ **提高工作效率** - 让AI帮你完成重复性任务
- ✅ **激发创意灵感** - 获得新的想法和解决方案
- ✅ **解决复杂问题** - 分解并处理复杂任务
- ✅ **学习新知识** - 快速理解和掌握新领域

## 提示词的基本组成

一个完整的提示词通常包含以下几个要素：

### 1. **角色设定 (Role)**
告诉AI它应该扮演什么角色。

```
你是一位专业的Python编程导师，擅长用简单易懂的方式解释复杂的概念。
```

### 2. **任务描述 (Task)**
明确告诉AI你需要它做什么。

```
请解释什么是递归函数，并举一个实际的例子。
```

### 3. **上下文信息 (Context)**
提供必要的背景信息。

```
我是一名初学者，刚接触Python一个月，希望了解递归在实际项目中的应用。
```

### 4. **输出格式 (Format)**
指定你希望的回答格式。

```
请用以下结构回答：
1. 简单的定义（一句话）
2. 一个生活中的类比
3. 代码示例
4. 实际应用场景
```

### 5. **约束条件 (Constraints)**
添加限制和要求。

```
- 使用简单的语言
- 避免专业术语
- 示例代码要有详细注释
- 总长度不超过500字
```

## 好的提示词 vs 差的提示词

### ❌ 差的提示词示例
```
什么是机器学习？
```
**问题：** 太宽泛，AI不知道你的背景和需求，可能给出过于简单或复杂的答案。

### ✅ 好的提示词示例
```
角色：你是一位数据科学教育专家
任务：向我解释什么是机器学习
上下文：我是市场营销人员，想了解如何将机器学习应用到客户分析中
格式：
1. 用通俗的语言定义（避免数学公式）
2. 举3个市场营销中的实际应用例子
3. 推荐入门学习资源
约束：总字数控制在800字以内，适合非技术人员理解
```

## 提示词的类型

根据用途不同，提示词可以分为以下几种类型：

| 类型 | 用途 | 示例 |
|------|------|------|
| **信息查询型** | 获取知识和信息 | "解释量子计算的基本原理" |
| **创作生成型** | 生成文本、代码等 | "写一首关于春天的诗" |
| **分析处理型** | 分析数据或文本 | "总结这篇文章的主要观点" |
| **对话交流型** | 多轮对话交流 | "帮我制定一个学习计划" |
| **指令执行型** | 执行具体操作 | "将这段代码从Java转换为Python" |

## 💡 学习建议

::: warning 注意事项
- **从简单开始**：先用简单的提示词练习，逐步增加复杂性
- **迭代优化**：不要期望一次就能写出完美的提示词，需要不断调整
- **保持清晰**：越具体的提示词，往往能得到越好的结果
- **善用上下文**：提供足够的背景信息帮助AI理解你的需求
:::
