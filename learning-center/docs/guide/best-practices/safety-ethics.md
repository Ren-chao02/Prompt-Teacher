# 安全与伦理考量

在使用AI和提示词时，必须考虑安全和伦理问题。

## 安全风险

### 1. 提示注入 (Prompt Injection)
恶意用户尝试操纵AI行为。

### 2. 数据泄露
敏感信息通过提示词泄露。

### 3. 有害内容生成
AI生成不当或有害的内容。

## 伦理考量

- **公平性** - 避免偏见和歧视
- **透明度** - 明确告知AI的使用
- **隐私保护** - 保护用户数据
- **责任归属** - 明确责任边界

## 防护措施

::: warning 重要原则
安全应该是设计的一部分，而不是事后补充。
:::
