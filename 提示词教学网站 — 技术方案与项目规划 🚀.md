# 提示词教学网站 — 技术方案与项目规划 🚀

## 一、数据库推荐：PostgreSQL ⭐ 强烈推荐

| 对比项             | PostgreSQL             | MySQL        | SQLite     |
| ------------------ | ---------------------- | ------------ | ---------- |
| **JSON 支持**      | ✅ 原生 JSONB，查询强大 | ⚠️ 有但不完善 | ❌ 不支持   |
| **Django 集成**    | ✅ 完美                 | ✅ 良好       | ✅ 仅开发用 |
| **结构化评分存储** | ✅ Array/JSONB 天然适配 | 一般         | 不适用     |
| **扩展性**         | ✅ 优秀                 | 良好         | 差         |
| **部署难度**       | 简单                   | 简单         | 无需部署   |

**选择理由**：你的核心功能是「多角度量化评分」，这会产生**结构化的嵌套数据**（如 `{清晰度: 85, 完整性: 72, 创造性: 90, ...}`），PostgreSQL 的 **JSONB 字段**可以完美存储和查询这类数据。

## 三、数据库表结构设计

```sql
-- 用户表 (Django Auth 自带，可扩展)
User (id, username, password, email, date_joined)

-- 练习记录表
PracticeRecord (
    id,
    user_id          -- 关联用户
    user_prompt      -- 用户输入的提示词
    system_prompt    -- 设置的系统提示词(场景)
    llm_response     -- 大模型原始回复
    
    -- 核心评分数据 (JSONB)
    scores           -- {清晰度:85, 完整性:72, 创造性:90, ...}
    
    -- 反馈信息
    suggestions      -- 修改建议 (文本/JSON)
    overall_score    -- 综合得分
    
    created_at       -- 创建时间
)

-- 学习资源表 (可选扩展)
LearningMaterial (
    id,
    title,
    content,
    category,        -- 分类标签
    order_index      -- 排序
)
```

## 五、分阶段实施计划

### 🔷 **第一阶段：基础框架搭建**
1. 初始化 Django 项目，配置 PostgreSQL 连接
2. 实现 Django 内置的用户认证系统（登录/注册/登出）
3. 创建首页模板，实现三个标签页的前端切换逻辑
4. 配置静态文件和前端基础样式

### 🔷 **第二阶段：核心练习功能** ⭐ 最关键
1. 设计并创建 `PracticeRecord` 模型
2. 编写 `llm_service.py` —— 封装与你服务器的 API 通信
3. 设计**评分系统提示词模板**（这是项目的灵魂！）：
   ```
   你是一个提示词评估专家。请从以下维度对用户的提示词进行评分(0-100)：
   - 清晰度：目标是否明确
   - 完整性：是否包含必要上下文
   - 结构化：格式是否合理
   - 创造性：是否有独特视角
   ...
   
   请返回 JSON 格式的评分结果和具体修改建议。
   ```
4. 实现练习页面的前后端交互（提交 → 调用 LLM → 存储结果 → 展示反馈）

### 🔷 **第三阶段：个人记录与学习模块**
1. 实现个人练习记录页面（列表展示 + 详情查看）
2. 添加数据可视化（评分趋势图表）
3. 构建提示词学习内容管理（CMS）

### 🔷 **第四阶段：优化与部署**
1. 前端美化（推荐使用 Bootstrap 或 Tailwind CSS）
2. 添加 WebSocket 支持实时流式输出（提升用户体验）
3. Docker 容器化部署
4. 性能优化与安全加固
